# Product scope — Windows only

## MVP must-have
- Windows 11 Home/Pro
- Protected standard child account
- SKÄRMRO Windows Service
- App allow/block
- Google Chrome management
- SKÄRMRO Browser Guard for Chrome
- Website rules
- Shorts experiment
- YouTube channel shadow-filter experiment
- Routines
- Pause Now
- Temporary access
- Auto restore
- Protection Health
- Policy Receipts
- Offline enforcement
- Junior Launcher

## Browser decision
Chrome is the only supported browser in MVP.

Other browsers may be added later if there is a validated need. Supporting several browsers in MVP would multiply policy, extension and QA complexity.

## Not MVP
- Microsoft Edge support
- Firefox support
- Brave/Opera support
- iOS
- Android
- macOS
- ChromeOS
- MDM / Intune dependency
- HTTPS MITM
- custom kernel driver
- screen recording
- keylogging
- private chat monitoring
